# 🛢️ Oil Price Analyzer | المحلل الذكي لأسعار النفط

An AI-powered web application that analyzes historical oil prices, provides statistical insights, and visualizes market trends using Python and Gradio.
تطبيق ويب مدعوم بالذكاء الاصطناعي يحلل أسعار النفط التاريخية، ويوفر إحصائيات دقيقة، ويرسم اتجاهات السوق باستخدام بايثون ومكتبة Gradio.

## 🚀 Features | المميزات
* **Real-time Data:** Fetches live oil prices from Yahoo Finance. (جلب بيانات النفط الحية).
* **Interactive UI:** Built with Gradio for an easy-to-use interface. (واجهة تفاعلية سهلة الاستخدام).
* **Data Visualization:** Generates dynamic charts for price trends. (رسم بياني ديناميكي لاتجاهات الأسعار).
* **Statistical Analysis:** Calculates max, min, and average prices. (حساب أعلى وأدنى ومتوسط الأسعار).

## 🛠️ Tech Stack | التقنيات المستخدمة
* Python
* Gradio
* Pandas & Matplotlib
* Yahoo Finance API
